First Release ​

Ezel is a modern plotting library.

Vitro (2020) ​

In 2020, I was testing my trading strategy in a HFT firm and there were two inconveniences:

  • A backtester in C/C++ had to export the result into a file and delegate to Python/JS for drawing the results.
  • A backtest took 10 minutes, and drawing the P&L chart with matplotlib took 30 minutes.

I wrote vitro, a C++ wrapper around Matplotlib, for the first issue.

Pyplotters (2021) ​

Then I wrote pyplotters, a Python wrapper for plotters-rs.
I liked plotters-rs. On every production Rust server, I added a /perfz endpoint that renders an HDR histogram of latencies.

Ezel PoC (2022-2024) ​

I started to build my own plotting library with piet-gpu.
The project was paused because the features I needed were missing from Rust's font and GPU rendering ecosystem.

Ezel (2026) ​

The whole tech stack is rebuilt from scratch.
Animation, Data Streaming, and Update.
I want to zoom a chart for a 24h backtest result to a specific point of time and inspect what happened within a short interval of 100ms.

Vello was replaced with a hand-written SDF shader and manual anti-aliasing.
Etagere (font atlas packer) was replaced with a GPU font shader.
Bezier curves are rendered to allow smooth zoom. The existing method used by most software does not support smooth zoom. (Chrome/Firefox zoom jumps straight to the final state. Also try zooming in any plotting library's demo.)
For an effortless experience, Ezel adopts the best font size, perceptual scaling, the APCA for contrast adjustment, and bubble cursor for object acquisition.

Customizable Hover Tooltip ​

Ezel uses Cassowary because CSS Flexbox can constrain only parent-child relationships, whereas Cassowary can constrain arbitrary nodes, as required for faceted plots.
Ezel measures the width of the y-axis label text and adds the constraint text width + 2 × margin ≤ y-axis width to the layout solver.

Auto Visual Balance ​

These are still open questions:

  • Where should Ezel place the title?
  • Where should Ezel place the legend box?
  • Where should Ezel place the data labels?
  • What is the optimal tick-label density?

For example, we could predict a saliency map with a small neural network and use it to evaluate candidate layouts. Alternatively, we could bin the pixels, identify the emptiest bin, and place the legend box there.

Incremental Work ​

  • Interactive chart libraries such as Vega implement reactivity, but they compare new series with old series to detect changes. This virtual DOM-style diff is expensive, especially when the data changes every frame.
  • A change to one node should not trigger a full recomputation of its descendant nodes.
  • Ezel's incremental dataflow forms a DAG of operation nodes. Even uploading a Vec<f64> to a wgpu::Buffer is implemented as a dataflow operation. The GpuUpload operation understands incremental changes such as Append and TruncateFront.
  • Misalignment between two wgpu::Buffer ring buffers is handled using a mirrored ring.
