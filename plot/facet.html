Facet ​

Facet templates a child Plot, expanding it into one panel per distinct value of a categorical variable.

Facet1 splits by a single variable; Facet2 splits by two, laying panels out in rows and columns.

Creating a Facet ​

Facet1::new(facet_var, item, share_scale) takes the variable to split by, the child Plot template, and whether panels share scales:

rust
let mut cell = Cartesian2::new();
cell.add_geometry({
    let mut geometry = ezel::cartesian2::Scatter::new("x", "y");
    geometry.color("group");
    geometry
});

let facet = Facet1::new("group", cell, true).with_data(data_frame);

Panels stack horizontally by default; with_direction(FacetDirection::Vertical) stacks them vertically.

Facet2 ​

Facet2::new(row_var, col_var, item, share_scale) splits the data by two variables and put them into a 2D layout.
with_skip_empty(true) skips a cell with no data.

rust
let facet = Facet2::new("region", "year", cell, true)
    .with_data(data_frame);

Scale Sharing ​

With share_scale = true, every panel shares the same scale instances: the same range, ticks, and zoom. With false, each panel scales to its own data and zooms independently.

Panel Titles ​

with_panel_title (Facet1) / with_row_title and with_col_title (Facet2) reserve a strip labeling each panel with its facet value:

rust
let facet = Facet1::new("group", cell, true)
    .with_panel_title(FacetPanelTitle {
        align_x: 0,
        align_y: -2, // strip above the panel
        label: label_style,
    });

Spacing ​

with_gap sets the spacing between adjacent panels; with_separator draws a line in the gap:

rust
let facet = Facet1::new("group", cell, true)
    .with_gap(Logical(8.0))
    .with_separator(FacetSeparator {
        thickness: Logical(1.0),
        color: Color::rgb(200, 200, 200),
    });
