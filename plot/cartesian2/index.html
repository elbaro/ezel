Cartesian2 ​

Cartesian2 is a Plot with orthogonal X and Y axes.

See Creating a Plot for the construction styles, and Geometry for the available geometries and their options.

Axes ​

Access X and Y axes for configuration:

rust
let mut plot = Cartesian2::new();
plot.x_axis.label = Some("Time (s)".into());
plot.y_axis.label = Some("Value".into());
plot.y_axis.scale = Scale::log();

See Scale for the available scales.

FieldTypeDescription
