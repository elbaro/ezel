Grid ​

Grid is a container Plot that lays out children Plots in a 2D grid.

Creating a Grid ​

push(row_range, col_range, plot) places a child Plot.

rust
let mut grid = Grid::new().with_title("Dashboard");
grid.push(0, .., overview); // row 0, spanning every column
grid.push(1, 0, detail_a);
grid.push(1, 2, detail_b);

Unoccupied cells stay empty:

Syntactic Sugar ​

Grid can be constructed by composing with | (horizontal) and / (vertical).

Horizontal Layout (|) ​

rust
let grid = plot1 | plot2 | plot3;

Vertical Layout (/) ​

rust
let grid = plot1 / plot2;

Combined Layouts ​

rust
let grid = (plot1 | plot2) / (plot3 | plot4);

Composition Behavior ​

  • Appending a Plot with | makes it span every existing row
  • Appending a Plot with / makes it span every existing column
