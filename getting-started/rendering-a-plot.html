Rendering a Plot ​

There are high-level APIs Plot::save() and Plot::show().
These internally use low-level APIs MemoryCanvas and WindowCanvas.

The low-level APIs should be used when you need more control, for example, to update data between frames.

High-level APIs ​

DestinationAPI
Fileplot.save(filepath, (w, h))
Web<ezel-plot src='..'>
Nativeplot.show((w, h))
Jupyterplot.show((w, h))
Terminalplot.render_to_terminal(size),
plot.render_to_kitty(&mut stdout, size, graph).await,
plot.render_to_sixel(&mut stdout, size, graph).await

Low-level APIs ​

MemoryCanvas ​

MemoryCanvas renders a Plot to a RGBA buffer Vec<u8>.
To generate an animated webp, you can stream this buffer to your webp encoder library.

rust
let mut canvas = MemoryCanvas::new(WIDTH, HEIGHT)?;
let graph = canvas.renderer_mut().graph().clone();

for frame in 0..60 {
  // .. update graph ..
  canvas.render(&plot)?;
  let pixels = pollster::block_on(canvas.read_buffer())?;
  // .. use pixels ..
}

WindowCanvas ​

WindowCanvas renders a Plot onto a wgpu::Surface which can be a native window or HTML <canvas>.

GpuRenderer ​

GpuRenderer renders onto wgpu::TextureView.
Use this to embed a plot in your wgpu application.

Auto Detecting Environment ​

plot.show(size) auto-detects the current environment and chooses the best render target.
