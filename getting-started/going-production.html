Emoji Font ​

Only COLRv1 is supported; CBDT is not supported.

COLRv1 is a vector format and is recommended; CBDT is a bitmap format. It's not decided if CBDT is going to be supported.

Some distributions package Noto Color Emoji in COLRv1 format, while others package it in CBDT format.

Dataviz Tips ​

Avoid Legends ​

Prefer direct labeling to legends. Legends make reading a plot difficult.

  • IBM Carbon Design System — Legends
  • UK Office for National Statistics — Chart elements
  • Practical Reporting — Avoid legends, footnotes, and other forms of "indirect" labeling
  • Depict Data Studio — Directly Labeling Your Line Graphs

Good Legends Location ​

It's controversial; there are good examples of putting legends in top, bottom, and right.

Prefer EplusM Scale over Log Scale ​

EplusM (Exponent plus Mantissa) is recently proposed, and it is claimed to be easier to read than Log scale.

Use different TickLabeling for dynamic data ​

Talbot (Extended Wilkinson) produces the optimal set of ticks for the current frame.
However, this can make the ticks extremely unstable in a streaming plot.
