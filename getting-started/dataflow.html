Dataflow ​

The dataflow module lets you draw plots with dynamic data and transformations.

To draw a dynamic plot, define a graph of input nodes and transform nodes.
Plot attributes can accept the dataflow nodes.

To update the data, push a change to the input nodes and the change automatically propagates.

Defining a Graph ​

Graph can be borrowed from a renderer, or built from scratch.

rust
let graph: &Graph = canvas.renderer.graph();

let graph = Graph::new();
// .. configure graph ..
canvas.renderer.set_graph(graph);

Node can have multiple outputs, and each output (outbound edge) is called a slot. Most nodes have a single slot.

rust
let input: NumericSeries = graph.numeric_input(vec![1.0, 10.0, 100.0])?;
let log: NumericSeries = input.log(10.0)?;
let gpu = log.to_gpu(gpu, gpu_buffers)?;

Input Node ​

Input nodes can be defined on a graph with initial data.

ConstructorReturnsData Type
graph.numeric_input(Vec<f64>)Result<NumericSeries, ConvertError>Growable f64 list
graph.numeric_input_bounded(Vec<f64>, Option<u32>)Result<NumericSeries, ConvertError>Bounded f64 ring
graph.u32_input(Vec<u32>)Result<U32Series, ConvertError>raw u32 values such as shape codes
graph.u32_input(Vec<u32>)?.as_color()ColorSeriespacked sRGBA colors
graph.categorical_input(["a", "b"])Result<CategoricalSeries, ConvertError>u32 codes + string catalog
graph.temporal_input(Vec<i64>, TimeUnit)Result<TemporalSeries, ConvertError>i64 timestamps
graph.string_input(["a", "b"])Result<StringSeries, ConvertError>String list

Series ​

Series is a typed handle to slots. Each series remembers which graph it belongs to.
For example, series.log() registers a new log node to the graph.

HandleHolds
NumericSeriesf64 values
U32Seriesu32 values
CategoricalSeriescodes and a catalog
TemporalSeriesi64 timestamps with a TimeUnit
StringSeriesstrings
Seriestype-erased enum over the series types

CategoricalSeries groups two slots. .catalog() -> StringSeries returns the unique values, while .codes() -> U32Series stores indices into that catalog. For example, catalog = ["A", "B", "C"], codes = [2, 2, 0, 1] represents ["C", "C", "A", "B"].

Update Data ​

MethodDelta
series.push(v)append one value
series.extend(&values)append a slice
series.prepend(&values)insert a slice at the front
series.set(index, v)overwrite one element
series.truncate_front(n)drop n values from the front
series.truncate_back(n)drop n values from the back
series.set_max_capacity(Some(n))ring bound: keep at most the newest n

These methods are available on numeric, raw u32, temporal, string, and
categorical input series. Categorical methods accept labels rather than raw
codes. For example, a series with catalog = ["A", "B", "C"] and
codes = [2, 2, 0, 1] behaves as ["C", "C", "A", "B"].

In browser JavaScript, an <ezel-plot> element's graph property returns a
JsGraph after mount. Use the input node ID recorded in the plot document to
retrieve its typed wasm-bindgen series wrapper. The wrappers expose the same
seven mutation names and request a redraw after a successful mutation:

js
const time = graph.numeric_input_by_node_id(1n)
const sine = graph.numeric_input_by_node_id(2n)
const cosine = graph.numeric_input_by_node_id(3n)
time.push(t)
sine.push(Math.sin(t))
cosine.push(0.8 * Math.cos(t))
rust
x.push(1000.0).unwrap();

let categories = graph
    .categorical_input(["C", "C", "A", "B"])
    .unwrap();
categories.set(2, "B").unwrap();
categories.push("D").unwrap();

Example ​

rust
use ezel::canvas::MemoryCanvas;
use ezel::prelude::*;
use pollster::FutureExt as _;
use webp::{AnimEncoder, AnimFrame, WebPConfig};

const WINDOW: usize = 120;
const DT: f64 = 0.05;
const FRAME_MS: i32 = 50; // 20 fps

fn main() {
    // MemoryCanvas has a Graph inside it.
    let mut canvas = MemoryCanvas::new(800, 500).unwrap();
    let graph = canvas.renderer_mut().graph().clone();

    let seed_x: Vec<f64> = (0..WINDOW).map(|i| i as f64 * DT).collect();
    let seed_y: Vec<f64> = seed_x.iter().map(|x| x.sin()).collect();
    let xs = graph.numeric_input(seed_x).unwrap();
    let ys = graph.numeric_input(seed_y).unwrap();

    let mut plot = Cartesian2::new().with_title("Sliding Window");
    plot.add_geometry(ezel::cartesian2::Line::new(xs.clone(), ys.clone()).with_size(2.0));

    let mut frames: Vec<Vec<u8>> = Vec::new();
    for frame in 0..60 {
        // One sample in, one sample out
        let x = (WINDOW + frame) as f64 * DT;
        xs.push(x).unwrap();
        ys.push(x.sin()).unwrap();
        xs.truncate_front(1).unwrap();
        ys.truncate_front(1).unwrap();

        canvas.render(&plot).unwrap();
        frames.push(canvas.read_buffer().block_on().unwrap());
    }

    let mut config = WebPConfig::new().unwrap();
    config.lossless = 1;
    let mut encoder = AnimEncoder::new(800, 500, &config);
    for (i, pixels) in frames.iter().enumerate() {
        encoder.add_frame(AnimFrame::from_rgba(pixels, 800, 500, i as i32 * FRAME_MS));
    }
    std::fs::write("sliding-window.webp", &*encoder.encode()).unwrap();
}
