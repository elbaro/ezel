Color ​

Ezel provides two types of color schemes:

  • Palette: a set of discrete colors
  • Ramp: a mapping from [0, 1] to colors

Palette ​

A palette is a list of colors. ezel::color::palette has built-in palettes.

rust
use ezel::color::Palette;

let categories: Palette = ezel::color::palette::OKABE_ITO;
// Requires the `color-colorbrewer` Cargo feature.
let ordered_categories: Palette =
    ezel::color::palette::colorbrewer::COLORBREWER_SEQUENTIAL_BLUES_9;

  • A qualitative palette represents unordered categories.

    Okabe-Ito

  • A sequential palette represents ordered categories from low to high.

    ColorBrewer Blues

  • A diverging palette represents ordered categories on either side of a central value.

    ColorBrewer RdBu

Ramp ​

A ramp maps a normalized (0.0~1.0) numeric value continuously to color.

rust
use ezel::color::Ramp;

let ramp: Ramp = ezel::color::ramp::VIRIDIS;

  • A sequential ramp represents values from low to high.

    Viridis

  • A diverging ramp represents values on either side of a central value.

    Coolwarm

  • A cyclic ramp represents values that wrap around, such as angles or phases, with matching colors at its endpoints.

    Twilight

  • A multi-sequential ramp represents two ordered regions with distinct meanings, such as sea depth and land elevation.

    Crameri Oleron

Choosing a Color Scheme ​

For more than a dozen categories, do not cycle the palette. Instead, combine the color with shape or line style, or use a dynamic palette designed for a larger category count.

Dynamic Color Schemes ​

There are helper functions that generate Palette or Ramp in runtime.

Palette::new creates a palette from a list of colors. OklabRamp::diverging creates a ramp from three colors, with the middle color at normalized position 0.5.

rust
use ezel::color::ramp::OklabRamp;
use ezel::color::{Color, ColorExt, Palette, Ramp};

let palette = Palette::new(vec![
    Color::rgb(230, 159, 0),
    Color::rgb(86, 180, 233),
    Color::rgb(0, 158, 115),
]);
let diverging = Ramp::new(OklabRamp::diverging(
    Color::rgb(40, 90, 170),
    Color::rgb(245, 245, 245),
    Color::rgb(180, 45, 45),
));
